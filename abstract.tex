\section{Introduction et contexte}
\label{sec:introduction}
Présenter ici le contexte général du projet, la problématique scientifique et les motivations qui justifient la recherche entreprise. Situer le travail par rapport à l'état de l'art~\cite{example2024}.


\section{Objectifs}
\label{sec:objectifs}
Formuler clairement les objectifs du projet et, le cas échéant, les hypothèses de recherche testées, par exemple sous la forme d'un modèle mathematique :
\begin{equation}
  f(x) = \sum_{i=1}^{n} \alpha_i \, \varphi_i(x), \qquad \alpha_i \in \mathbb{R}
  \label{eq:modele}
\end{equation}
ou $\varphi_i$ désigne une fonction de base et $\alpha_i$ les coefficients associés (cf. Eq.~\eqref{eq:modele}).

\section{Méthodologie}
\label{sec:methodologie}
Décrire la démarche scientifique, les méthodes, outils, données et protocoles expérimentaux utilisés pour répondre aux objectifs fixés.

\label{sec:resultats}
Présenter les résultats obtenus (ou attendus si le projet est en  cours), en s'appuyant si besoin sur la Figure~\ref{fig:illustration} et sur des éléments quantitatifs.

\section{Instructions}
Les deux rendus devront contenir les sections suivantes:
\begin{itemize}
  \item pour le rendu intermédiaire:
    \begin{itemize}
      \item introduction/contexte/problématique
      \item objectifs envisagés
      \item méthodologie envisagée
      \item modèle mathématique, modèle physique et/ou algorithmique
      \item analyse succincte de la littérature succincte de la litérature sur le sujet
      \item planification prévisionnelle du projet (intégrant les résultats attendus et la répartition des tâches)
      \item références bibliographiques (au moins 8 références)
    \end{itemize}
  \item pour le rendu final:
    \begin{itemize}
      \item introduction/contexte/problématique
      \item objectifs
      \item démarche et méthodologie scientifique
      \item modèle mathématique, modèle physique et/ou algorithmique
      \item résultats obtenus et discussion
      \item conclusion et perspectives
      \item références bibliographiques (au moins 5 références)
    \end{itemize}
\end{itemize}

Les références bibliographiques doivent être citées dans le texte et listées à la fin du document. Les références peuvent être de différents types : articles scientifiques, chapitres de livres, actes de conférences, thèses, rapports techniques, sites web, logiciels, jeux de données, normes, prépublications, etc. Les références sont automatiquement formatées par \LaTeX à partir du contenu du fichier \texttt{references.bib}. Ce fichier est à remplir de manière exhaustive. L'usage d'un logiciel de gestion de bibliographie (Zotero, etc.) est fortement recommandé pour générer le contenu du fichier \texttt{references.bib}.
